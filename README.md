# مسار — منصة دراسة التمويل (النسخة 0.1)

منصة ويب عربية بحسابات مستخدمين لإدارة عملاء التمويل: ملف لكل عميل، مستنداته، طلباته لدى الجهات، ودراسة أهلية فورية وفق ضوابط ساما مع مطابقة جهات التمويل.

## التشغيل المحلي
```bash
npm install
npm run seed        # قاعدة بيانات تجريبية (يحذف الحالية!)
npm run build && npm start     # أو npm run dev
# افتح http://localhost:3000
```
الدخول التجريبي: `admin@masar.local` / `Masar@2026` (وأيضاً analyst@ و officer@ و viewer@). غيّر كلمات المرور قبل أي استخدام حقيقي.
يتطلب Node.js 22.13 أو أحدث (يستخدم SQLite المدمج في Node). الاختبارات: `npm test`.

## الأمان وحماية البيانات
- كلمات المرور bcrypt (12)، جلسات بتوكن عشوائي يُخزَّن مُجزّأً، كوكي HttpOnly/SameSite، انتهاء بعد 10 ساعات.
- قفل الحساب 15 دقيقة بعد 5 محاولات فاشلة.
- صلاحيات على الخادم لكل إجراء (لا تعتمد على إخفاء الأزرار).
- الملفات خارج المجلد العام بأسماء عشوائية، فحص النوع والمحتوى، 10MB حداً، تنزيل لمسجل فقط ومُسجَّل.
- رقم الهوية مقنّع افتراضياً، وإظهاره مُسجَّل. حذف الملف يتلف المستندات (حق الإتلاف).
- ترويسات أمان (منع الإطار، nosniff…)، ومنع فهرسة محركات البحث.

## المعمارية
Next.js 15 (App Router + Server Actions) · React 19 · TypeScript · Tailwind 4 · SQLite (node:sqlite).
- `lib/engine.ts`: محرك الأهلية — دوال نقية مختبرة (`tests/`).
- `lib/schema.ts`: المخطط بـ SQL قريب من PostgreSQL للانتقال إلى Postgres لاحقاً.
- `lib/auth.ts`: الجلسات والأدوار والتدقيق. `app/actions.ts`: كل عمليات الكتابة.

## خارطة الطريق المقترحة
1. **الاستضافة الإنتاجية**: PostgreSQL + تخزين ملفات مشفر في منطقة سعودية (متطلبات PDPL لنقل البيانات خارج المملكة)، نسخ احتياطي يومي، نطاق خاص.
2. **التحقق بخطوتين** للمستخدمين وتسجيل الدخول برمز.
3. **قراءة المستندات آلياً**: استخراج الراتب من تعريف الراتب وكشف الحساب، والالتزامات من تقرير سمة.
4. **إشعارات واتساب/بريد** للعميل بالمستندات الناقصة وتغير الحالة، وبوابة عميل لرفع مستنداته.
5. **قاعدة معايير موثقة لكل جهة** تحدّث دورياً مع تاريخ التحقق، وتقارير أداء (نسب القبول لكل جهة، مدة الصرف).
6. **عمولات وفوترة** لكل ملف معتمد.

> ⚠️ معايير الجهات في البيانات التجريبية تقديرية للعرض فقط. يجب على فريق الائتمان إدخال المعايير الفعلية من كل جهة.

## النشر على Vercel
استورد المستودع من vercel.com/new بالإعدادات الافتراضية (Next.js). أمر البناء `npm run build` يجهز تلقائياً على Vercel قاعدة بيانات عرض وهمية ومفتاح توقيع جلسات عشوائي.
- اختياري: أضف متغير البيئة `MASAR_SECRET` (نص عشوائي طويل) لتبقى الجلسات صالحة بين عمليات النشر.
- ⚠️ نسخة Vercel الحالية تحفظ البيانات في `/tmp` مؤقتاً (تعود للوضع التجريبي عند إعادة التشغيل). للحفظ الدائم يلزم ربط قاعدة PostgreSQL (المرحلة القادمة).
